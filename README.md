# FreshCart - Task 5

A simple, responsive grocery shopping web app made with separate HTML, CSS, and JavaScript files.

## Features

- Product cards created with JavaScript
- Search products by name
- Filter products by category
- Add, remove, increase, and decrease cart items
- Cart total and item count
- Cart is saved in the browser with `localStorage`
- Responsive layout for desktop and mobile screens
- No external libraries, fonts, or image files

## Run the project

1. Open the `ApexPlanet_Task5` folder.
2. Double-click `index.html`.
3. It will open in your web browser.

## Files

- `index.html` - page structure
- `style.css` - all design and responsive rules
- `script.js` - products, search, filters, cart, and checkout behavior
